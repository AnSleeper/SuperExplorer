# 超级资源管理器（SuperExplorer）

一个 .NET 8 + WPF 编写的**多面板媒体资源浏览器**：左侧文件夹树 + 右侧可同时打开多个文件夹面板，只展示图片、GIF、视频、文本和文件夹，主打缩略图浏览、拖拽整理和可撤销的文件操作。无第三方依赖，单文件发布，便携式运行。

## 功能特性

- **多面板工作区**：最多同时打开 6 个文件夹，并排 / 网格两种布局，面板可拖拽换位，分隔条宽度自动记忆
- **左侧文件夹树**：常用文件夹收藏、"此电脑 → 磁盘 → 目录"懒加载、磁盘用量进度条、"设为顶层"（把任意文件夹设为树根，隐藏上级与同级）
- **缩略图浏览**：图片按实际显示尺寸解码；视频首帧与文件夹真实预览走 Windows Shell 提取；文本文件显示前 10 行内容
- **手写虚拟化网格**：只渲染可视区域内的卡片，卡片对象复用，大目录滚动流畅
- **文件操作**：拖拽移动 / 复制（按住 Ctrl 拖 = 复制）、Ctrl+C / Ctrl+V、F2 重命名、新建文件夹、删除进回收站（可选确认弹窗）
- **50 步撤销栈**：移动、复制、删除、重命名、新建文件夹均可撤销，删除撤销通过 Shell COM 从回收站还原
- **个性化**：6 套配色主题、缩略图大小、界面字号阶梯、面板宽度权重，全部跨会话记忆
- 全局异常捕获写 `logs/error.log`，出问题不闪退

## 快捷键

| 按键 | 功能 |
|---|---|
| Ctrl+C / Ctrl+V | 复制 / 粘贴选中项（同时写入系统剪贴板） |
| Ctrl+Z | 撤销上一步操作 |
| Delete | 移入回收站 |
| F2 | 重命名选中项 |

## 构建

需要 .NET SDK 8.0（Windows）：

```
cd src/SuperExplorer
dotnet publish -c Release
```

产出在 `bin/Release/net8.0-windows/win-x64/publish/`，为自包含单文件 exe（约 138 MB），可直接拷贝运行。

设置保存在 exe 旁的 `data/settings.json`，日志写入 `logs/`，不写注册表、不碰 AppData。

## 图标

`src/SuperExplorer/app.ico` 已随源码附带。若需重新生成，把图标原图放到 `封面素材/超级资源管理器程序图标.jpg`（素材不入库，需自备），再运行 `tools/make_icon.ps1`。
